# Исходное задание — Assignment 7: Euro Converter

## Статус

Assignment 7. В системе указано: `To do: Make a submission` — работу требуется сдать.

## Что требуется

- Создать приложение Euro Converter, которое получает валютные курсы из Exchange Rates API: <https://api.apilayer.com/exchangerates_data/latest>.
- Получить бесплатный API-ключ на странице сервиса: <https://apilayer.com/marketplace/exchangerates_data-api>.
- Передавать API-ключ в заголовках запроса; дополнительные сведения предлагается смотреть в документации API.
- Использовать компонент `Picker` для отображения валют и заполнить его значениями из ответа запроса.
- После нажатия кнопки `Convert` перевести введённую сумму из выбранной валюты в евро и показать результат.
- Для получения кодов валют из объекта ответа предлагается использовать `Object.keys()`: <https://developer.mozilla.org/en-US/docs/Web/JavaScript/Reference/Global_Objects/Object/keys>.

## Ожидаемый результат

Пользователь вводит сумму, выбирает валюту из списка, полученного от API, и нажимает `Convert`. Приложение показывает рассчитанную сумму в евро.
